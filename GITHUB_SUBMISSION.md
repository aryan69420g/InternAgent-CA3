# Submission checklist

Repository: https://github.com/aryan69420g/InternAgent-CA3

## Included
- Streamlit UI and Python multi-agent workflow
- Synthetic CSV dataset
- Automated unit tests and GitHub Actions workflow
- Architecture diagram source (Mermaid)
- PowerPoint presentation
- Editable Word technical report
- Problem brief and five-minute presenter/viva notes

## Before handing in
1. Replace any unfilled cover-page identity fields in the Word report.
2. Run the application with streamlit run app.py.
3. Run tests with python -m unittest discover -s tests -v.
4. Open the PowerPoint and verify it opens on the computer used for the demo.
5. Submit the repository URL and ensure visibility is Public if the instructor needs access.
